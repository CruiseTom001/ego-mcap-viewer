没有找到可用于创建运行环境的 Python。
======================================================

系统要求：
  Windows 10 1809（内部版本 17763）或更高
  64 位 Windows
  64 位 Python 3.10 ～ 3.13（推荐 Python 3.12）

方法一：安装 Python 3.12 x64
  1. 从 https://www.python.org/downloads/windows/ 下载 64 位安装程序
  2. 安装时勾选 “Add python.exe to PATH”
  3. 重新双击“启动查看器.bat”

方法二：手工指定已有 Python
  在本软件目录新建 python.txt，只写一行 python.exe 的完整路径，例如：

  C:\Users\你的用户名\AppData\Local\Programs\Python\Python312\python.exe

程序会拒绝 32 位、低于 3.10 或高于 3.13 的解释器。
详细检查结果见 python-candidates.log 和 startup-error.log。
